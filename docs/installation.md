# Installation

Clone the repository.

```bash
git clone https://github.com/hosnizaaraoui/OOPS.git
```

Move into the repository.

```bash
cd OOPS
```

Move into a project.

```bash
cd <project>
```

Create a virtual environment.

```bash
python -m venv .venv
```

Activate it.

Linux

```bash
source .venv/bin/activate
```

Install dependencies.

```bash
pip install -r requirements.txt
```
